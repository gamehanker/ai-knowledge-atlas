AI Agent：Tool Use

把語言模型從「回答問題」延伸成「使用工具完成任務」。工具使用型 Agent 能選工具、傳參數、讀取工具結果，再組織最終回覆。

本篇目錄
核心概念運作流程簡單範例常見誤解理解測驗

核心概念

AI Agent（人工智慧代理）可以根據目標選擇動作、使用工具並利用結果繼續完成任務。Tool Use（工具使用）是常見的 Agent 能力之一。

例如有人問：「我平時成績 82，占 60%，期末占 40%，要總成績 85，期末需要幾分？」模型可以呼叫計算工具，而不只是憑語言推測答案。

運作流程

使用者提出問題→模型選擇工具及參數→程式執行工具→模型整理結果

工具呼叫通常包含工具名稱與參數；真正執行運算、讀取檔案或呼叫外部服務的，是有權限的程式環境。

重要安全原則：工具權限應採最小必要原則；涉及刪除、付款、發送等動作，應有適當的使用者確認與檢查。

簡單範例

成績試算

設期末成績為 x，要讓加權總分達到 85：

82 × 0.6 + x × 0.4 = 85 49.2 + 0.4x = 85 x = (85 - 49.2) / 0.4 = 89.5

工具可回傳「需要 89.5 分」，Agent 再把結果解釋給使用者。如果計算結果大於 100，Agent 也應清楚說明目標不可達成。

工具描述（Tool Schema）

可定義工具名稱如 required_exam_score，以及 current_score、current_weight、final_weight、target_score 等數值參數。清楚的 Schema 有助模型正確選用工具。

常見誤解

  • 錯誤：模型產生工具呼叫文字，就代表工具已經執行。
    正確：主程式必須驗證並執行工具，再將結果回傳模型。
  • 錯誤：所有問題都需要呼叫工具。
    正確：簡單的定義問題可以直接回答；需要精確運算或外部資料時，工具更有價值。

理解測驗

當模型決定呼叫 required_exam_score 時，下列何者正確？

  1. 模型只要說出工具名稱，就一定完成運算
  2. 程式應檢查參數、執行工具，並將結果提供給模型
  3. 每次呼叫都應讓模型取得所有電腦權限
查看答案與解析

答案：2。模型提出工具使用請求，程式環境負責安全地執行與回傳結果。
