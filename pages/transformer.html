Transformer：Self-Attention

Self-Attention（自注意力）讓一個 token 在計算表示時，參考序列中其他 token 的資訊。理解 Q、K、V，就是理解它的第一步。

本篇目錄
核心概念運作流程簡單範例常見誤解理解測驗

核心概念

Transformer（轉換器）是一種擅長處理序列資料的神經網路架構。它的核心設計之一是 Self-Attention（自注意力）。

假設一句話是：「小明把書放到桌上，然後拿起它。」當模型處理「它」時，會參考前面相關詞語的資訊，而不是只看「它」這一個字。

重點：Attention 是依據輸入與學習到的參數計算資訊關聯的權重，不代表模型一定能正確理解代名詞。

運作流程

每個 token 的輸入表示會分別透過線性轉換，得到三個向量：

  • Query（查詢，Q）：目前想尋找什麼資訊？
  • Key（鍵，K）：我可以用什麼特徵被找到？
  • Value（值，V）：真正提供給後續計算的資訊。
Q 與 K
計算相似分數→Softmax
轉換為權重→對 V
做加權總和

在一般 scaled dot-product attention 中，常用公式是：

Attention(Q, K, V) = softmax(QKᵀ / √dₖ) V

其中 dₖ 是 Key 向量的維度。除以 √dₖ，是為了控制點積數值的尺度。

簡單範例

假設某個 token 對其他三個 token 的 Attention 權重分別是 0.1、0.7、0.2，而其 Value（簡化為純量）分別是 2、4、10。

輸出 = 0.1×2 + 0.7×4 + 0.2×10 = 5.0

這表示第二個 token 對這次輸出的貢獻權重最大。實際模型使用的是向量，並會在不同注意力頭中學到不同的關係。

常見誤解

  • 錯誤：用 Query 與 Value 算權重。
    正確：用 Query 與 Key 算權重，然後加權 Value。
  • 錯誤：一個 token 只能看到自己。
    正確：未遮罩的 Self-Attention 可以參考序列其他 token；具因果遮罩的模型不能看未來 token。

理解測驗

哪一個是 Self-Attention 最符合的計算順序？

  1. Q 與 V 算權重，再加權 K
  2. Q 與 K 算權重，再加權 V
  3. 直接平均所有 token，不需要權重
查看答案與解析

答案：2。Q、K 先決定注意力權重，再用權重對 V 做加權總和。
